Banners do topo

A faixa escura no alto da página inicial, que troca sozinha. Ligar uma campanha é um clique.

Três coisas que este carrossel faz e a maioria não faz:
  • Funciona sem JavaScript. Se o script falhar, o primeiro banner continua lá, inteiro e legível — o topo do site nunca fica vazio
  • Para de girar quando a pessoa mexe nos controles. Quem clicou decidiu; o site para de decidir por ela
  • No celular não gira sozinho — só com o dedo. Lá não existe "passar o mouse" para pausar
Por isso o primeiro banner é o que importa: pesquisa de usabilidade mostra que a maioria das pessoas nunca chega ao segundo. Ponha nele a mensagem que você quer que todo mundo leia.

Categorias da Loja

Como os produtos se agrupam na página Materiais. Cada categoria pode ter subcategorias dentro dela.

Como isso aparece no site: a categoria vira um título com a linha verde embaixo. A subcategoria vira um subtítulo menor, dentro dela. Produto que não estiver em nenhuma subcategoria aparece logo abaixo do título da categoria, antes das subcategorias — então você não precisa criar subcategoria se não quiser.

Gerar os arquivos

O painel não publica nada. Ele gera os arquivos; quem publica é você, no GitHub — o mesmo gesto de sempre.

Confira antes de subir. Estes botões abrem a página montada numa aba nova, com o conteúdo que está no painel agora. Nada é publicado — é só para você olhar.

index.html

A página inicial, com os banners do topo e o equilíbrio entre Loja e Serviços. O único arquivo com script — e feito para o primeiro banner aparecer mesmo sem ele.

dados/conteudo.json

A memória do painel. É este arquivo que você abre da próxima vez para continuar de onde parou. Sempre baixe este.

materiais.html

A página da Loja, com os cartões já montados em HTML puro. Nenhum JavaScript monta produto — se o navegador falhar, a loja continua lá.

servicos.html

A página de Serviços, com as áreas montadas. Mesma lógica: HTML pronto, sem depender de script.

links.js

Os preços e checkouts que as seis páginas de produto leem. É o que impede o preço de ter dois donos.

Como subir

Igual ao que você já faz. Nada de token, nada de linha de comando.

  1. Copie os arquivos baixados para a pasta do site, cada um no seu lugar — o conteudo.json vai dentro de dados/, os outros três na raiz.
  2. No GitHub, abra mouracassio/nucleo-exato e clique em Add file → Upload files.
  3. Arraste os arquivos e escreva no commit o que mudou. Ex.: "produto novo: apostila de NR-35".
  4. Commit. Em menos de um minuto o site republica sozinho.
  5. Confira em navegador de verdade — nunca por link de prévia. Preço aparece como R$ -- em fetch, e isso não é bug.
Guarde o conteudo.json. Ele é a memória do painel. Se você perdê-lo, o site continua no ar normalmente — mas o painel volta a abrir sem saber o que você já cadastrou.
